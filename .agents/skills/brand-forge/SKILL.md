# Brand Forge

Use only after distinguishing redesign from rebranding and checking the preservation contract.

## Resource routing

- Load [brand asset workflow](./resources/workflow.md) for preservation checks, brand profile fields, component-skill routing, validation, and provenance.
- Then load only the required installed component skill: `generate-logo`, `generate-social`, `generate-graphic`, or `generate-doc-template`.

Never overwrite a customer source asset. Logo or paid imagery generation requires explicit approval.
