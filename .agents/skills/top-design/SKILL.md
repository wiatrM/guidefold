# Top Design

Build a distinctive experience around one strong point of view. Use this file as the router and the pinned upstream resources as the detailed craft reference.

## Workflow

1. Define the brand idea, audience, desired emotion, signature interaction, and performance/accessibility constraints.
2. Score the starting direction with the upstream weighted rubric.
3. Establish typography and composition before animation. Give every motion beat a narrative or interaction purpose.
4. Prototype the highest-risk signature moment early, with mobile and reduced-motion fallbacks.
5. Build the remaining page as a paced sequence of dense and quiet moments without sacrificing navigation clarity.
6. Measure runtime behavior, remove jank and gratuitous effects, then score the result and list gaps to 10/10.

## Completion gate

Deliver a score by category, explicit signature moments, responsive and reduced-motion behavior, performance evidence, accessibility findings, and remaining risks. Reject default-font, centered-everything, effect-for-effect's-sake, and 60fps-breaking implementations.
