# Motion pattern routing

Choose the smallest pattern that expresses the story. Combine patterns only when each has a distinct narrative job.

## Cinematic scroll video

Use for a transformation with meaningful intermediate frames. Map clamped scroll progress to a bounded frame cache or meaningful seek delta, smooth visual sampling, preserve object-cover math, and finish on an exact final frame. Add scroll runway only when the beat sheet needs it. Keep overlays sparse and reversible.

## Loop video

Use for ambient texture without required temporal order. Keep it short, seamless, muted, and subordinate to content. Pause it offscreen and replace it under reduced motion or save-data.

## Marquee and sticky stack

Use marquee for breadth or catalogue energy, never essential reading. Duplicate content without duplicate screen-reader announcements. Sticky cards preserve DOM order, scale gently, release cleanly, and never trap scroll.

## Carousel

Use for a small finite comparison set. Preload images, expose previous/next controls and labels, support keyboard input, lock overlapping transitions, and provide a static accessible fallback.

## Spotlight reveal

Use to compare two aligned states. Canvas masking is enhancement only. Default to the base image, avoid per-frame data URL generation on constrained devices, and provide touch/static behavior.

## Editorial museum

Use controlled overlap, specimen media, chapter navigation, and dramatic type. Decorative objects are inert. Heavy dissolve/filter transitions require a static crossfade fallback.

## Validation matrix

Test 360×800, 390×844, 768×1024, and 1440×900; fast and reverse scroll; resize/rotation; refresh mid-page; reduced motion; save-data; offline/media failure; keyboard-only use; and stable terminal state.
