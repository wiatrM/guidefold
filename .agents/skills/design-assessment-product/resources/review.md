# Assessment product review

## Contract checks

- Confirm the rendered hook, promise, three dimensions, ten scored questions, five qualification questions, bands, insights, and next steps match the approved brief.
- Confirm the public score uses only the declared best-practice answers and every score from 0 through 10 maps to exactly one band.
- Confirm every result gives three useful insights and a valid preserved or approved next step.
- Confirm copy makes no unevidenced duration, conversion, research, expertise, diagnostic, urgency, price, or availability claim.

## Data and preservation checks

- Inspect runtime requests and storage. in-browser-only must make no answer/contact request and persist no answers.
- For handoff or lead capture, compare every submitted field, target, consent string, privacy string, and failure state with the approved contract.
- Fail on IP enrichment, undeclared analytics payloads, answer logging, required phone without approval, invented endpoint, or changed protected form names.
- Verify original routes, navigation, anchors, primary action, logo, legal copy, and SEO constraints still work outside the assessment.

## Interaction checks

- Complete the flow at all band boundaries and with each qualification path.
- Test keyboard-only use, focus movement, error announcements, progress semantics, back/restart behavior, zoom, mobile viewport, reduced motion, refresh, and JavaScript or request failure.
- Treat a broken score, inaccessible question, lost preserved path, undeclared data transfer, or false claim as release-blocking.
