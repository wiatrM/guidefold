# Preregistered clustering sensitivity QA

This is a supplementary uncertainty check frozen before retrieval outcomes. It does not replace the primary paired query bootstrap, change the advancement gate, select a model, or alter generated text or retrieval settings.

Build an undirected graph on the 2,048 evaluation query IDs. Connect two queries when their positive gold-skill sets intersect; use connected components, including transitive connections and singleton queries, as resampling units. Construct the graph from the full cohort before applying any reporting stratum. This avoids splitting a dependency component when a path goes through a query outside that stratum. No query text or retrieval result is needed to define components.

Use the exact same per-query metric differences as the primary analysis, with independently recomputed metrics from saved rankings. For each reported stratum, retain the nonempty intersections of full-cohort components with that stratum. Draw G components uniformly with replacement, where G is the number of nonempty components, for each of 5,000 bootstrap replicates using numpy default_rng(20260907). For each metric, sum all query-level differences in sampled components and divide by the total number of sampled query observations. The denominator varies across bootstrap replicates; do not take an unweighted mean of component means. The point estimate remains the original query-weighted mean. Report percentile 95% intervals in percentage points.

Report the primary C_metadata_queries minus A_original contrast for recall@10 and all-gold-selected@4, along with the same diagnostic contrasts/strata/metrics as the main report if available. Compare whether the overall recall@10 interval excludes zero with the original query-bootstrap result. Any disagreement must be stated explicitly; neither test is substituted after observing the result. The completeness and no-gold-enriched point guards are unchanged.

Report component counts, singletons, minimum/median/p95/maximum component size, largest component's fraction of query observations, and effective component count (sum(n)^2 / sum(n^2)) for the full cohort and each stratum. Flag fewer than 10 nonempty components or a component containing more than half the stratum as an unstable cluster-bootstrap regime. In the one-component case the mechanically degenerate interval is not informative. Keep all components; do not remove or split a large component to narrow an interval.

This graph captures shared positive labels only. Queries can remain dependent through common source repositories, templates, unjudged relevant documents, shared distractors, or the common corpus/index. Therefore this is a sensitivity analysis, not proof of independent sampling or a population-valid confidence interval. The corpus is fixed and the sample is internal public TRAIN, not an independent user sample. Multiple secondary contrasts are descriptive and unadjusted.

Implementation may fix demonstrable calculation errors but must preserve this estimator, seed, replicate count and reporting rules. Record any correction. Never train, tune thresholds, or rewrite the original experiment results in this QA.
