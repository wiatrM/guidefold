# Relay Helm charts

One chart per Meridian service. Charts are published to the internal OCI registry from release tags only.

## Layout

    charts/
      _template/               # scaffold copied by `make chart-new NAME=<service>`
      meridian-common/         # library chart: meridian.labels, meridian.probes, meridian.securityContext
      <service>/
        Chart.yaml             # version = chart, appVersion = image
        values.yaml            # complete, documented defaults
        values.schema.json     # additionalProperties: false
        templates/
        tests/                 # helm-unittest suites
        README.md              # generated by helm-docs; CI diffs it

## Values conventions

- `global.imageRegistry`: required, no default; every image is `<registry>/<repository>@<digest>`.
- `image.repository`, `image.digest`: never `image.tag`.
- `resources.requests` and `resources.limits`: required for every container.
- `existingSecret`: charts reference secrets by name and never template secret data.
- Environment overlays live in `../values/<env>/<service>.yaml` and may only override keys that exist in `values.yaml`.

## Versioning

patch = template fix, minor = new value, major = removed or renamed value. Bumps follow the root release process.
